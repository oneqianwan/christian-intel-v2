# Christian Intel (FaithMate)
## 全球基督教行业情报平台

---

### 一句话定位
Christian Intel = **Bloomberg + Crunchbase + LinkedIn + Perplexity** 的融合体，专为基督教生态打造。

### 解决什么痛点
全球基督教行业：
- 10万+机构分散在官网、Facebook、YouTube、新闻中
- 没有任何平台能回答：“菲律宾有哪些AI教会？”
- 没有任何平台能回答：“谁负责 Innovation？”
- 投资者、基金会寻找合作对象需要数百小时调研

### 系统能力演示
1. **全景Dashboard**：行业覆盖率、缺口优先级、最弱机构排序
2. **智能问答**：“菲律宾有哪些AI教会？” -> 自动国家分析 -> 机构筛选 -> 投资建议
3. **竞争分析**：“PCEC的竞争格局” -> 同类机构对比 + 合作机会
4. **投资网络**：查询投资方 Portfolio、共同投资关系
5. **历史追踪**：任何字段变更都有记录，形成时间轴

### 技术架构
7层数据体系：Country -> Organization -> People -> Content -> Relation -> History -> Evidence

Multi-Agent Brain：Intent -> Data -> Analysis -> Report 自动编排

### 商业模式
- 免费：行业搜索、机构查询
- Pro：高级报告、关系图谱、AI分析
- Enterprise：API、Dashboard、CRM集成
- **最终变现：数据资产（覆盖全球 + 持续更新 + 历史变化 = 不可复制的壁垒）**
