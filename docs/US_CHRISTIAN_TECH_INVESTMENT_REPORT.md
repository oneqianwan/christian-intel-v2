   - 投资网络围绕 Gloo、YouVersion / Life.Church、Pushpay、Subsplash、Tithe.ly、BibleProject、RightNow Media 形成

2. **AI成熟度极高（91.8%）**
   - 说明美国基督教机构数字化程度全球领先
   - 但 People 覆盖率仅 27.9%，负责人信息仍是最大缺口

3. **投资网络集中度高**
